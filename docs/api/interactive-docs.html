Quick Start Example

Here's how to make your first API call:

curl -X POST "https://api.prometheus-ai.com/api/v1/helios/analyze/geological" \ -H "Authorization: Bearer YOUR_JWT_TOKEN" \ -H "Content-Type: application/json" \ -d '{ "data_type": "seismic", "spatial_extent": { "min_lat": 45.0, "max_lat": 46.0, "min_lon": -122.0, "max_lon": -121.0 }, "parameters": { "frequency_range": [1.0, 10.0], "magnitude_threshold": 2.0 } }'

Authentication

To authenticate your requests:

  1. Obtain a JWT token from the authentication endpoint
  2. Enter the token in the field above
  3. All subsequent API calls will include the authentication header
# Get authentication token curl -X POST "https://api.prometheus-ai.com/auth/login" \ -H "Content-Type: application/json" \ -d '{ "username": "your_username", "password": "your_password" }'
